O que vamos testar?

  1. 1O navegador carrega o SDK do Firebase.
  2. 2A configuração Web do projeto ateliepsi é carregada.
  3. 3A conta Google é reconhecida pelo Firebase.
  4. 4Após atualizar esta página, a sessão permanece ativa.

Faça o teste: entre com Google, atualize usando “Verificar sessão novamente” e, por último, saia da conta. O status de cada etapa aparecerá ao lado.

No iPhone: abra esta página diretamente no Safari, fora do navegador integrado do ChatGPT ou de outras redes sociais, para evitar bloqueios à janela do Google.

Importante: esta página é independente e não está vinculada ao banco de progresso dos alunos.
